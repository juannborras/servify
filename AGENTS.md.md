
## Contexto del proyecto

Este repositorio contiene Servify, una aplicación desarrollada para Seminario de Integración Profesional.

El objetivo principal es tener una app funcional, estable y defendible en una presentación académica.

## Antes de trabajar

## Reglas para Codex

- No modificar código sin entender primero el flujo general.
- No cambiar rutas, endpoints, nombres de entidades o variables de entorno sin justificarlo.
- Priorizar cambios mínimos y seguros.
- Mantener la arquitectura actual salvo que se pida explícitamente refactorizar.
- Antes de cambios grandes, explicar diagnóstico y plan.
- Después de modificar, listar archivos cambiados y motivo.
- Si la documentación queda desactualizada, actualizar los archivos en docs/.

## Prioridades

1. Que la app levante correctamente.
2. Que la demo sea estable.
3. Que el código sea entendible para defensa oral.
4. Que frontend y backend mantengan contratos claros.
5. Que la documentación refleje el estado real del proyecto.
